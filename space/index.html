Korean PII Replacement Benchmark

Measures how the form of PII replacement affects what an LLM can still answer from masked Korean text. All masked conditions cover the same gold PII spans; only the replacement form changes.

⚠️ Controlled experiment with gold PII spans (detection errors excluded). Scores reflect the replacement method, not the end-to-end performance of any product.

  • The same value within a document always maps to the same token.
  • Mapping tables and original values are never sent to the model; restoration runs locally after the answer.
  • Hash and typed tokens are both restorable. The difference is whether the model can see that a slot holds a phone number.

Tasks

  • Single-value lookup: e.g. "What is Minji's phone number?" The restored answer must exactly match the gold value.
  • Multi-value extraction: list all identifiers (phone numbers, emails, account, card and ID numbers) as an array. F1 penalizes both missing and extra values.

Limitations

  • Gold spans are given, so detection quality is not measured.
  • One answering model and one run per condition.
  • Lookup and extraction only; do not generalize to summarization, classification or reasoning.
  • Scores above the original text likely reflect that type labels make targets easier to pick, not a general capability gain.
  • *** scores zero partly because these tasks require returning the original value.
