Korean PII Replacement Benchmark

Replacing PII with typed tokens keeps LLM answers as accurate as the unmasked text; plain *** masking makes them unusable.

Extraction F1 on 500 Korean documents: typed token (LLM Capsule method) 99.3, original text 98.0, hash token 76.7, *** 0.

The table shows the extraction task: list every identifier in the text (phone, email, account, card and ID numbers). F1 counts both missed and wrong values; 100 is perfect. Results for single-value lookup are under Detailed results.

How replacement works

  • Every condition hides the same gold PII positions; only the replacement form changes.
  • The same value within a document always maps to the same token.
  • Original values and the mapping table (which token stands for which value) are never sent to the model. Restoring the original values happens on the user's side after the answer.
  • Hash and typed tokens are both restorable. The difference is whether the model can see that a slot holds a phone number.

Limitations

  • Gold spans are given, so detection quality is not measured.
  • One answering model and one run per condition.
  • Lookup and extraction only; do not generalize to summarization, classification or reasoning.
  • The typed token scores slightly above the original text likely because a label such as [전화번호_A] points to the target. It does not mean replacement makes answers better than the original.
  • *** scores zero partly because these tasks require answering with the original value.
