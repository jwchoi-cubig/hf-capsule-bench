# Korean PII Replacement Benchmark

> **한국어 요약** 같은 위치의 개인정보를 가리고 가리는 방식만 달리해 LLM에 같은 질문을 던졌습니다. 별표(\*\*\*)로 가리면 0점, 무작위 코드로 바꿨다가 복원하면 문서 76.7점에 그쳤지만, LLM Capsule처럼 `[전화번호_A]` 같은 항목명 표식으로 바꿨다가 복원하면 문서 99.3점으로 가리지 않은 원문(98.0점)과 같은 수준이었습니다.

Korean PII Replacement Benchmark measures how the **form of PII replacement** affects what an LLM can still answer from masked Korean text. This is an open sample of 1,000 annotated items (500 documents from OpenPII, 500 dialogues from KDPII) used in our evaluation. All masked conditions cover the same gold PII spans; only the replacement form changes.

We find that plain `***` masking makes identifier lookup impossible, an untyped hash token loses 22 to 29 points of F1 even after restoration, and a **typed, entity-indexed token** such as `[전화번호_A]` ("phone number A") stays at the level of the unmasked text. This typed, entity-indexed replacement with local restoration is the approach used in [LLM Capsule]({UTM 링크: LLM Capsule 비교 자료}).

## Results

Multi-value extraction F1 (n = 500 per dataset, answering model gpt-6-luna)

| Replacement | Restore | OpenPII | KDPII |
| --- | --- | --- | --- |
| Typed entity token `[전화번호_A]` (LLM Capsule method*) | yes | **99.3** | **96.3** |
| Hash token `96dcb10b8009` | yes | 76.7 | 67.4 |
| Plain masking `***` | no | 0.0 | 0.0 |
| Original text (reference) | n/a | 98.0 | 96.3 |

\* The replacement form LLM Capsule uses. PII positions are fixed across conditions, so scores isolate the replacement method.

Single-value accuracy, confidence intervals and method details: [results page](https://huggingface.co/spaces/CUBIGCorp/korean-pii-replacement-results).

## Dataset structure

> 필드 구성은 공개 범위 확정 후 맞춤 (이현규 이사님 확인)

| Field | Description |
| --- | --- |
| `id` | Item id |
| `source` | `openpii` or `kdpii` |
| `text` | Original text with synthetic or annotated PII |
| `pii_spans` | Gold PII spans and types |
| `question_single` / `answer_single` | Single-value lookup question and gold answer |
| `question_multi` / `answer_multi` | Multi-value extraction question and gold answers |

## Source data and license

Built from [OpenPII 1.5M](https://huggingface.co/datasets/ai4privacy/pii-masking-openpii-1.5m) (Korean validation, © Ai4Privacy / Ai Suisse SA) and [KDPII Revised](https://zenodo.org/records/16759166), both CC BY 4.0. Questions and answers were generated by code from the original annotations. Please credit the original datasets.

## Limitations

- Gold spans are given, so PII detection quality is not measured.
- One answering model, one run per condition; lookup and extraction tasks only.
- Not an end-to-end score of any product.
